Utiliser Mirador pour consulter les documents numériques des Collections spéciales

Mirador est une visionneuse IIIF permettant de consulter des documents numériques en haute résolution directement dans un navigateur Web. Elle est particulièrement adaptée aux collections patrimoniales comme les manuscrits, livres anciens, estampes, cartes et documents d'archives.

Dans les Collections spéciales, Mirador permet d'explorer les documents numérisés, de naviguer entre les pages, d'effectuer des agrandissements précis, de comparer plusieurs documents et, lorsque disponible, d'utiliser les données OCR pour rechercher du texte à l'intérieur des documents.

Ce guide présente les principales fonctionnalités de Mirador et explique comment utiliser cette visionneuse avec les ressources IIIF des Collections spéciales.

Qu'est-ce que IIIF ?

IIIF (International Image Interoperability Framework) est un ensemble de standards ouverts développés par et pour les institutions culturelles (bibliothèques, musées, archives) afin de permettre la diffusion d'images de haute qualité sur le Web, l'interopérabilité entre les collections numériques de différentes institutions, la comparaison côte à côte de documents et l'annotation et le partage de recherches.

Pour en savoir plus, consultez le site officiel : https://iiif.io.

Qu'est-ce que Mirador ?

Mirador est une visionneuse IIIF développée pour les bibliothèques, archives, musées et institutions de recherche. Elle utilise les standards IIIF afin d'afficher des documents numériques provenant de différentes sources de façon uniforme.

Contrairement à une visionneuse traditionnelle liée à une seule plateforme, Mirador peut ouvrir tout manifeste IIIF compatible. Un même document peut donc être consulté dans différentes applications, indépendamment de l'institution qui l'héberge.

Dans les Collections spéciales, Mirador est intégré directement aux notices des documents numériques afin d'offrir une expérience de consultation adaptée aux documents patrimoniaux.

Comment utiliser Mirador pour naviguer dans un document

Mirador offre plusieurs zones et outils pour explorer un document : le panneau d'information (métadonnées, transcription, voir aussi, autres formats), l'espace de travail Mirador (fenêtres, disposition) et la barre supérieure (titre, plugins).

Panneau d'information (métadonnées, transcription, voir aussi, autres formats)

Le panneau d'information permet d'accéder aux métadonnées descriptives, aux transcriptions, aux liens « Voir aussi » et aux autres formats disponibles pour le document.

Recherche dans Mirador avec surbrillance

Mirador permet de rechercher un terme dans le texte d'un document lorsque des données OCR sont disponibles. Les résultats sont surlignés directement dans les pages.

Affichage OCR avec texte en surimpression

Lorsque des données OCR sont disponibles, Mirador peut afficher le texte reconnu en surimpression sur l'image, ce qui facilite la lecture et la vérification des résultats.

Activez l'affichage OCR dans les options de la fenêtre.
