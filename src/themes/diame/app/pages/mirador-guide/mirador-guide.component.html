Utiliser Mirador pour consulter les documents numériques des Collections spéciales

Mirador est une visionneuse IIIF permettant de consulter des documents numériques en haute résolution directement dans un navigateur Web. Elle est particulièrement adaptée aux collections patrimoniales comme les manuscrits, livres anciens, estampes, cartes et documents d'archives.

Dans les Collections spéciales, Mirador permet d'explorer les documents numérisés, de naviguer entre les pages, d'effectuer des agrandissements précis, de comparer plusieurs documents et, lorsque disponible, d'utiliser les données OCR pour rechercher du texte à l'intérieur des documents.

Ce guide présente les principales fonctionnalités de Mirador et explique comment utiliser cette visionneuse avec les ressources IIIF des Collections spéciales.

Qu'est-ce que Mirador ?

Mirador est une visionneuse IIIF développée pour les bibliothèques, archives, musées et institutions de recherche. Elle utilise les standards IIIF afin d'afficher des documents numériques provenant de différentes sources de façon uniforme.

Contrairement à une visionneuse traditionnelle liée à une seule plateforme, Mirador peut ouvrir tout manifeste IIIF compatible. Un même document peut donc être consulté dans différentes applications, indépendamment de l'institution qui l'héberge.

Dans les Collections spéciales, Mirador est intégré directement aux notices des documents numériques afin d'offrir une expérience de consultation adaptée aux documents patrimoniaux.

Ouvrir un document dans Mirador

Les documents des Collections spéciales sont automatiquement ouverts dans Mirador lorsqu'une visionneuse IIIF est disponible. Vous pouvez également utiliser le manifeste IIIF d'un document dans une installation indépendante de Mirador.

Depuis les Collections spéciales

Pour consulter un document dans Mirador :

  1. Accédez à la notice du document numérique.
  2. Ouvrez la visionneuse IIIF associée au document.
  3. Le document est automatiquement chargé dans Mirador.
  4. Utilisez les outils disponibles pour consulter les différentes pages.

À partir d'un manifeste IIIF

Un manifeste IIIF peut également être ouvert directement dans Mirador. Cette méthode permet notamment d'utiliser un document provenant d'une autre institution ou de comparer plusieurs ressources.

  1. Copiez l'adresse du manifeste IIIF.
  2. Ouvrez une instance compatible de Mirador.
  3. Choisissez l'option permettant d'ajouter un document ou un manifeste.
  4. Collez l'adresse du manifeste.

Naviguer dans un document

Les documents patrimoniaux sont souvent composés de plusieurs pages. Mirador facilite la navigation entre les différentes parties d'un document grâce à une interface conçue pour la consultation de livres, manuscrits et autres documents multipages.

Se déplacer entre les pages

Utilisez la barre de navigation située au bas ou sur le côté de la visionneuse pour parcourir les pages du document. Vous pouvez également sélectionner directement une page à partir des miniatures lorsque celles-ci sont disponibles.

Utiliser les miniatures

Le panneau des miniatures permet d'obtenir une vue d'ensemble du document. Il est particulièrement utile pour retrouver rapidement une page précise dans un ouvrage volumineux.

Les miniatures peuvent être affichées ou masquées selon l'espace disponible dans la fenêtre de consultation.

Utiliser le zoom et explorer les images

Les images IIIF sont diffusées à la demande selon le niveau de détail nécessaire. Mirador permet ainsi d'examiner des documents numérisés en très haute résolution sans avoir à télécharger l'image complète.

Agrandir une image

Utilisez les boutons de zoom pour agrandir progressivement l'image. Cette fonction permet d'observer des détails difficiles à voir à taille normale, comme :

  • annotations manuscrites ;
  • détails d'une illustration ;
  • caractères typographiques anciens ;
  • marques de possession ou notes marginales.

Déplacer l'image

Lorsque l'image est agrandie, cliquez et déplacez l'image afin d'examiner différentes zones du document.

Cette fonctionnalité est particulièrement utile pour les documents comprenant des détails graphiques complexes ou une mise en page ancienne.

Comparer plusieurs documents

Une des principales forces de Mirador est la possibilité d'afficher plusieurs documents simultanément dans une même fenêtre.

Cette fonction permet notamment de comparer :

  • différentes éditions d'un même ouvrage ;
  • plusieurs exemplaires d'un manuscrit ;
  • des documents provenant de différentes institutions ;
  • des images ou illustrations similaires.

Ajouter un deuxième document

Pour ajouter une nouvelle ressource :

  1. Ouvrez le menu d'ajout de document.
  2. Entrez l'adresse d'un manifeste IIIF.
  3. Le nouveau document apparaît dans un second panneau.

Comparaison côte à côte

Les panneaux peuvent être organisés afin d'afficher plusieurs documents simultanément. Cette présentation facilite l'analyse comparative dans les travaux de recherche et d'enseignement.

Recherche textuelle et OCR

Certains documents des Collections spéciales disposent de données OCR permettant d'effectuer des recherches dans le texte numérisé. Lorsque cette information est disponible, Mirador peut afficher le texte associé aux pages du document.

Rechercher un mot dans un document

La recherche textuelle permet de retrouver rapidement des occurrences d'un terme dans un document volumineux, sans devoir parcourir chaque page manuellement.

  1. Ouvrez l'outil de recherche dans Mirador.
  2. Entrez un terme ou une expression.
  3. Consultez les résultats affichés dans les pages correspondantes.

Ouvrez la notice d'un document et cliquez sur le lien IIIF.

Ajoutez le manifeste IIIF dans Mirador.

Utilisez la vue livre pour consulter un ouvrage.

Limites de la recherche OCR

La qualité des résultats dépend de la qualité de la reconnaissance optique des caractères (OCR). Les documents anciens peuvent présenter certaines difficultés, notamment :

  • caractères anciens ou typographies historiques ;
  • lettres difficiles à reconnaître ;
  • mise en page complexe ;
  • annotations manuscrites.

Utiliser un manifeste IIIF dans d'autres visionneuses

Les manifestes IIIF ne sont pas limités à Mirador. Comme ils reposent sur des normes ouvertes, ils peuvent être ouverts dans plusieurs applications compatibles. Cela facilite la consultation, la comparaison et la réutilisation des documents numériques.

Mirador

Mirador est particulièrement adapté aux documents patrimoniaux complexes. Il permet notamment :

  • de consulter des documents multipages ;
  • de comparer plusieurs documents côte à côte ;
  • de naviguer rapidement entre les pages ;
  • d'effectuer un zoom de haute précision ;
  • d'utiliser les outils de recherche textuelle lorsque des données OCR sont disponibles.

Universal Viewer

Universal Viewer est une autre visionneuse IIIF largement utilisée par les bibliothèques, archives et institutions patrimoniales. Son interface est conçue pour une consultation simple et intuitive des documents numériques.

Clover IIIF Viewer

Clover IIIF Viewer est une visionneuse légère permettant d'intégrer rapidement des ressources IIIF dans des pages Web ou des applications numériques.

Comment ouvrir un manifeste ?

  1. Copiez l'adresse du manifeste IIIF du document.
  2. Ouvrez une visionneuse compatible IIIF.
  3. Choisissez l'option permettant d'ouvrir ou d'ajouter un manifeste.
  4. Collez l'adresse du manifeste.
  5. Le document est chargé automatiquement.

Informations techniques

IIIF repose sur plusieurs normes complémentaires permettant de décrire, diffuser et enrichir les documents numériques. Ces standards sont utilisés par les institutions afin de rendre leurs collections interopérables.

IIIF Presentation API

La Presentation API décrit la structure d'un document numérique : ses pages, son organisation, ses métadonnées et les ressources qui lui sont associées.

C'est cette API qui permet aux visionneuses comme Mirador de comprendre comment afficher un document.

IIIF Image API

La Image API permet d'obtenir différentes versions d'une même image sans créer plusieurs fichiers. Elle permet notamment de modifier :

  • la taille de l'image ;
  • la région affichée ;
  • la rotation ;
  • la qualité ou le format.

IIIF Search API

Foire aux questions

Pourquoi le manifeste s'affiche-t-il en JSON ?

Le manifeste IIIF est un fichier destiné aux applications compatibles IIIF. Il contient les informations nécessaires pour afficher le document, mais n'est pas conçu comme une page Web destinée à être lue directement.

Puis-je utiliser un manifeste provenant d'une autre bibliothèque ?

Oui. Les visionneuses compatibles IIIF peuvent généralement ouvrir des manifestes provenant de différentes institutions, tant que ceux-ci respectent les normes IIIF.

Puis-je télécharger les images originales ?

Cela dépend des droits associés au document. Certaines ressources permettent le téléchargement des images haute résolution, tandis que d'autres limitent leur réutilisation.

Pourquoi certains documents ne permettent-ils pas la recherche textuelle ?

La recherche textuelle nécessite des données OCR ou des transcriptions compatibles. Les documents qui ne possèdent pas ces données peuvent uniquement être consultés sous forme d'images.

Est-ce que Mirador fonctionne seulement avec les Collections spéciales ?

Non. Mirador peut ouvrir des ressources provenant de toute institution utilisant IIIF. Le même outil peut donc être utilisé pour consulter des collections numériques provenant de nombreuses bibliothèques, archives et musées.
