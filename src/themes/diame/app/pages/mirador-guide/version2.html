Utiliser Mirador pour consulter les documents numériques des Collections spéciales

Mirador est une visionneuse IIIF permettant de consulter des documents numérisés en haute résolution directement dans un navigateur Web. Elle est utilisée pour explorer des livres anciens, manuscrits, estampes, cartes, photographies et autres documents patrimoniaux.

Dans les Collections spéciales, Mirador permet de naviguer entre les pages d'un document, d'effectuer des agrandissements précis, de comparer plusieurs documents et, lorsque disponible, d'utiliser les données OCR pour rechercher du texte dans les documents numérisés.

Ce guide présente les principales fonctionnalités de Mirador et explique comment exploiter les ressources IIIF mises à disposition par les Collections spéciales.

Qu'est-ce que Mirador ?

Mirador est une visionneuse compatible avec le International Image Interoperability Framework (IIIF). Elle permet d'afficher des documents numériques provenant de différentes institutions tout en utilisant une interface commune.

Contrairement à une simple page Web contenant une image, Mirador exploite un manifeste IIIF qui décrit la structure complète d'un document : ses pages, ses images, ses métadonnées et les ressources associées.

Grâce à IIIF, un même document peut être consulté dans différentes visionneuses compatibles et intégré dans des environnements de recherche, d'enseignement ou de diffusion scientifique.

Ouvrir un document dans Mirador

Les documents compatibles IIIF des Collections spéciales peuvent être ouverts directement dans Mirador depuis leur notice descriptive.

Depuis une notice des Collections spéciales

Pour consulter un document :

  1. Ouvrez la notice du document numérique.
  2. Repérez le lien ou le bouton IIIF.
  3. Cliquez sur la visionneuse afin d'ouvrir le document dans Mirador.
  4. Le document est automatiquement chargé.

Trouver le manifeste IIIF

Chaque document IIIF possède un manifeste. Ce fichier contient les informations nécessaires à Mirador pour afficher correctement le document.

Si vous souhaitez ouvrir le document dans une autre application IIIF, copiez simplement l'adresse du manifeste.

Ouvrir un manifeste externe

Mirador peut également ouvrir des documents provenant d'autres bibliothèques ou institutions utilisant IIIF.

  1. Copiez l'adresse du manifeste IIIF.
  2. Ouvrez l'outil d'ajout de ressource dans Mirador.
  3. Collez l'adresse du manifeste.
  4. Cliquez sur ajouter.

Comprendre l'interface de Mirador

L'interface de Mirador est organisée autour de plusieurs panneaux et outils permettant d'adapter l'affichage du document selon vos besoins.

Les principaux éléments de l'interface sont :

  • le panneau latéral contenant les informations du document ;
  • la zone principale d'affichage de l'image ;
  • les outils de zoom et de navigation ;
  • les options d'affichage des pages ;
  • les outils de recherche et d'annotation lorsqu'ils sont disponibles.

Le panneau d'information

Le panneau latéral permet d'accéder aux informations associées au document : titre, auteur, description, métadonnées et liens disponibles.

Naviguer dans un document

Les documents patrimoniaux numérisés contiennent souvent plusieurs pages. Mirador permet de parcourir rapidement l'ensemble du document.

Utiliser les miniatures

Le panneau des miniatures offre une vue d'ensemble des pages du document. Il permet de repérer rapidement une section particulière et d'accéder directement à une page.

Se déplacer entre les pages

Utilisez les boutons de navigation ou sélectionnez directement une page dans les miniatures.

Choisir une vue d'affichage

Mirador propose plusieurs modes d'affichage adaptés aux différents types de documents.

Vue simple

La vue simple affiche une seule page à la fois. Elle convient particulièrement aux photographies, estampes ou images isolées.

Vue livre

La vue livre affiche deux pages côte à côte, comme un ouvrage ouvert. Elle est recommandée pour les livres anciens, manuscrits et documents multipages.

Vue galerie

La vue galerie affiche plusieurs pages sous forme de vignettes. Elle permet d'obtenir rapidement une vue d'ensemble d'un document.

Explorer les images en haute résolution

Les images IIIF sont diffusées dynamiquement selon le niveau de détail demandé. Mirador permet ainsi d'examiner des documents de très grande résolution sans télécharger l'image complète.

Agrandir une image

Utilisez les boutons de zoom pour examiner les détails du document :

  • caractères typographiques ;
  • annotations manuscrites ;
  • illustrations ;
  • marques de provenance.

Déplacer l'image agrandie

Lorsque l'image est agrandie, cliquez et faites glisser l'image afin d'explorer différentes zones du document.

Comparer plusieurs documents

Mirador permet d'afficher plusieurs ressources simultanément. Cette fonctionnalité est particulièrement utile pour comparer des éditions différentes, des exemplaires ou des documents provenant de plusieurs collections.

Ajouter un deuxième document

  1. Cliquez sur l'option d'ajout de ressource.
  2. Copiez l'adresse d'un deuxième manifeste IIIF.
  3. Ajoutez le document dans un nouveau panneau.

Affichage côte à côte

Les documents peuvent être consultés simultanément afin de faciliter l'analyse comparative.

Recherche OCR et texte

Certains documents des Collections spéciales disposent de données OCR (reconnaissance optique des caractères) permettant d'effectuer des recherches dans le texte des documents numérisés.

Lorsque l'OCR est disponible, Mirador peut afficher les informations textuelles associées aux pages et permettre de retrouver rapidement des occurrences dans un document volumineux.

Effectuer une recherche dans un document

  1. Ouvrez l'outil de recherche dans Mirador.
  2. Entrez un mot ou une expression.
  3. Consultez les pages contenant les résultats.
  4. Cliquez sur un résultat pour accéder directement à l'emplacement correspondant.

Affichage du texte OCR

Lorsque les données OCR sont disponibles, le texte reconnu peut être associé à l'image de la page. Cette fonction permet de visualiser la correspondance entre l'image numérisée et le texte reconnu.

Limites de l'OCR

La qualité des résultats dépend de la qualité de la reconnaissance automatique. Les documents anciens peuvent présenter certaines difficultés :

  • typographies anciennes ;
  • lettres longues (comme le « s » long) ;
  • mise en page complexe ;
  • annotations manuscrites ;
  • images ou illustrations intégrées au texte.

Télécharger et réutiliser les ressources

Les ressources IIIF peuvent être utilisées dans différents contextes de recherche, d'enseignement ou de création numérique.

Réutiliser un manifeste IIIF

Le manifeste IIIF peut être copié et utilisé dans d'autres applications compatibles. Il constitue le point d'entrée normalisé vers un document numérique.

Droits d'utilisation

Les possibilités de téléchargement et de réutilisation des images dépendent des conditions associées à chaque document. Consultez toujours les informations sur les droits indiquées dans la notice du document.

Utiliser un manifeste dans d'autres visionneuses IIIF

Les manifestes IIIF ne sont pas limités à Mirador. Ils peuvent être ouverts dans plusieurs applications compatibles.

Universal Viewer

Universal Viewer est une visionneuse IIIF utilisée par plusieurs bibliothèques et archives. Elle offre une interface simple pour consulter des documents numériques.

Clover IIIF Viewer

Clover est une visionneuse légère permettant d'intégrer rapidement des documents IIIF dans des sites Web ou applications numériques.

Ouvrir un manifeste

  1. Copiez l'adresse du manifeste IIIF.
  2. Ouvrez une visionneuse compatible.
  3. Choisissez l'option d'ajout d'un manifeste.
  4. Collez l'adresse du manifeste.

Informations techniques

IIIF repose sur plusieurs normes ouvertes permettant de décrire, diffuser et enrichir les documents numériques.

IIIF Presentation API

La Presentation API décrit la structure d'un document : ses pages, son organisation, ses métadonnées et les ressources associées. 

{
  "type": "Manifest",
  "label": {
    "fr": [
      "Exemple de document IIIF"
    ]
  }
}

IIIF Image API

La Image API permet de demander différentes versions d'une image sans générer plusieurs fichiers. Elle permet notamment de modifier la taille, la région ou la rotation. 

https://serveur-iiif.org/image/12345/full/1200,/0/default.jpg

IIIF Search API

La Search API permet aux applications compatibles de rechercher du texte associé à un document numérique. 

{
  "type": "AnnotationPage",
  "items": [
    {
      "type": "Annotation"
    }
  ]
}

IIIF Annotation API

La Annotation API permet d'associer des annotations à une image : commentaires, transcriptions, zones d'intérêt ou informations scientifiques.

Foire aux questions

Pourquoi le manifeste s'affiche-t-il en JSON ?

Le manifeste est un fichier destiné aux applications compatibles IIIF. Il décrit la structure du document mais n'est pas conçu comme une page Web traditionnelle.

Puis-je ouvrir un manifeste provenant d'une autre institution ?

Oui. Les visionneuses IIIF peuvent généralement ouvrir des manifestes provenant de différentes bibliothèques, archives et musées.

Pourquoi certains documents n'ont-ils pas de recherche OCR ?

La recherche textuelle nécessite des données OCR ou une transcription. Les documents disponibles uniquement sous forme d'images ne permettent pas cette fonction.

Puis-je utiliser Mirador avec mes propres documents ?

Oui. Toute ressource disposant d'un manifeste IIIF compatible peut être ouverte dans Mirador.
